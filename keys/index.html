    Seat Keys

    Purpose

    Manage exam seat key assignments, monitor usage, and ensure every student has proper access.

    Key Metrics

    • Total Keys → Total licenses issued for your school.
    • Used Keys → Keys that have already been assigned to students.
    • Available Keys → Licenses that are still free to be distributed.

    Tip

    Always keep track of available keys before exam periods to avoid shortages.

    Filters

    • Status Filter → View all keys, only used, or only unused.
    • Grade Filter → Focus on keys linked to specific grade levels.
    • Exam Filter → Narrow results to NAFS, Qudurat, or Tahsili exams.

    Note

    Filters save time when you need to quickly locate unused keys for a certain class or subject.

    Table Explanation

    The main table lists every seat key with important details:

    • Key Code → Unique identifier for each license.
    • Creation Date → When the key was generated.
    • Key Status → Shows if the key is used or unused.
    • Used Date → The date a student first activated the key.
    • Time Left → Remaining validity before expiration.
    • Exam → Exam type connected to the key.
    • Grade → The grade level assigned to the key.
    • Student Name → Displays the assigned student (if any).

    Student Details

    Clicking a student’s name opens a pop-up with:

    • AILA ID → The student’s system identifier.
    • Last Login → The most recent login date.

    Tip

    Use this to confirm whether assigned students are actively logging in.

    🧠 How to Use

    1. Use the search bar to find a key by student, code, or exam.
    2. Apply filters to refine the list by grade, exam, or status.
    3. Assign unused keys to students who haven’t yet received one.
    4. Check the student details pop-up to confirm login activity.
    5. Regularly review the metrics at the top to balance seat usage.
